# Mid Exam Topics - Deep Learning ICTS6361

## Topic Distribution

**Core Fundamentals**
- Neural Network Basics
- Forward propagation
- Basic activation functions (ReLU, sigmoid)
- Simple loss functions (MSE, cross-entropy)
- Backpropagation
- Chain rule application
- Gradient computation basics

**Essential Optimization**
- Training Techniques
- Mini-batch gradient descent
- Basic regularization (L2, dropout)
- Learning rate concepts
- Hyperparameter Basics
- Learning rate, batch size
- Simple tuning strategies

**Practical ML**
- Train/Dev/Test Sets
- Proper data splitting
- Basic error analysis
- ML Strategy
- When to collect more data
- Human-level performance comparison
